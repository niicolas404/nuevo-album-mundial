# nuevo-album-mundial


nombre: nicolas giovanni jara herrera

descripción de app: es un contador de figuritas para que el usuario coleccionista lleve el orden de su album del mundial 2026.

instrucciones para ejecutar: desde la terminal, entra a cd album-mundial-2026, luego instala npm con "npm install", y finalmente echala a correr con "npm run dev"

declaracióm de copílot: desde la etapa 2 a la 5 fui asistido por IA.
